# retro-lan

Everything for a retro LAN party.

## Game servers

| Directory | What |
|-----------|------|
| [gameservers/cs16-srv](gameservers/cs16-srv) | Counter-Strike 1.6: two dedicated servers (classic maps, fun maps) with map voting, game modes (Deathmatch, GunGame), bots and admin menus. Docker Compose. |
| [gameservers/ut-srv](gameservers/ut-srv) | Unreal Tournament (UT99, 469e) and UT2004: one dedicated server each with map voting (incl. game type), bots and web admin. Docker Compose, uses the Laclede's LAN images. |
