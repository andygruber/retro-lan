## Install

There is no download here: install **Counter-Strike** from Steam (it runs natively on Windows and Linux).

## Join the servers

- **Server browser:** *Find Servers* → **LAN** tab.
- **By IP:** open the console (key below <kbd>Esc</kbd>, enable it under *Options → Keyboard → Advanced → Enable developer console*) and type

  ```
  connect {{server_ip}}:27015
  ```

  for *Classic*, or port `27016` for *Fun*.

Custom maps are downloaded from the server when you join.

## Chat commands

Type in chat (<kbd>Y</kbd>):

| Command | What |
|---|---|
| `/menu` | Menu with everything below (tip: `bind F3 lanmenu` in the console) |
| `rtv` | Rock the vote: map vote now once 60 % typed it |
| `/maps` or part of a name (`dust`) | Nominate a map for the next vote |
| `/votemode` | Vote for Classic / Deathmatch / GunGame / GunGame FFA |
| `/votekick` | Vote to kick a player |
| `timeleft`, `nextmap` | Info |
| `/rank`, `/top15`, `/stats` | Stats |

A map vote starts by itself 2 minutes before the time limit (in GunGame: when someone wins). Bots fill the teams up to 10 players and leave as people join.
