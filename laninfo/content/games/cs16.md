## Install: Steam (recommended)

Install *Counter-Strike* from Steam. It runs natively on Windows and Linux and is what the servers are tested with.

## Alternative: NextClient

Only if you can't use Steam: a standalone CS 1.6 client, in the downloads.

### Windows

1. Run `CS_1.6_NextClient_2.5.3.exe` and follow the installer.
2. Start *CS 1.6 NextClient* from the Start Menu or the desktop.

### Linux

NextClient is a Windows program. Run the installer with Wine (or add it to Lutris/Bottles), then start the installed game the same way:

```sh
wine CS_1.6_NextClient_2.5.3.exe
```

The Steam version is the easier choice on Linux.

> [!NOTE]
> NextClient players can join because the servers run in LAN mode. If they are switched to internet mode (`SV_LAN=0`), only Steam players get in.

## Join the servers

- **Server browser:** *Find Servers* → **LAN** tab.
- **By IP:** open the console (key below <kbd>Esc</kbd>, enable it under *Options → Keyboard → Advanced → Enable developer console*) and type

  ```
  connect {{server_ip}}:27015
  ```

  for *Classic*, or port `27016` for *Fun*.

Custom maps are downloaded from the server when you join.

## Chat commands

Type in chat (<kbd>Y</kbd>):

| Command | What |
|---|---|
| `/menu` | Menu with everything below (tip: `bind F3 lanmenu` in the console) |
| `rtv` | Rock the vote: map vote now once 60 % typed it |
| `/maps` or part of a name (`dust`) | Nominate a map for the next vote |
| `/votemode` | Vote for Classic / Deathmatch / GunGame / GunGame FFA |
| `/votekick` | Vote to kick a player |
| `timeleft`, `nextmap` | Info |
| `/rank`, `/top15`, `/stats` | Stats |

A map vote starts by itself 2 minutes before the time limit (in GunGame: when someone wins). Bots fill the teams up to 10 players and leave as people join.
