## Install

Unpack `UT.zip` to a folder (e.g. a USB stick or `Downloads`) and keep the structure as it is. The `install_files` folder must be writable, the Windows installer writes its `install.log` there.

### Windows

1. Double-click `install-windows.bat`.
2. Enter the install folder, or press <kbd>Enter</kbd> for the default `C:\Games\UnrealTournament`.
3. Confirm the administrator prompt for the Visual C++ runtime at the end.

The folder can also be passed directly:

```bat
install-windows.bat "D:\Games\Unreal Tournament"
```

The installer unpacks the game, Bonus Pack 4 and the 469f patch, creates the Start Menu folder *Unreal Tournament GOTY* (with *Unreal Tournament* and *UnrealEd*) and installs the Visual C++ runtime.

**Uninstall:** there is no uninstaller. Delete the install folder and the Start Menu folder `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Unreal Tournament GOTY`.

If something fails, look at `install_files\install.log`.

### Linux

1. Install the required tools once (needs internet or a package mirror):

   ```sh
   sudo dnf install jq 7zip-standalone-all tar curl   # Fedora
   sudo apt install jq p7zip-full tar curl            # Debian / Ubuntu
   sudo pacman -S jq 7zip tar curl                    # Arch
   ```

2. Open a terminal in the unpacked folder and run:

   ```sh
   bash install-linux.sh
   ```

3. Accept the EULA and answer whether to create the menu entry and desktop shortcut.

The game goes to `~/.local/share/OldUnreal/UnrealTournament`. At the end the installer shows the command to start it. Useful options:

| Option | Meaning |
|---|---|
| `-d <folder>` | Install to another folder |
| `--application-entry install\|skip` | Create the menu entry without asking |
| `--desktop-shortcut install\|skip` | Create the desktop shortcut without asking |
| `-e` | Also install UnrealEd (runs via Wine/umu-launcher) |

## Join the server

- **Server browser:** *Multiplayer → Find Internet Games*, then the **LAN** tab.
- **By IP:** press <kbd>Tab</kbd> (or open the console) and type `open {{server_ip}}:7777`.

Maps you don't have are downloaded from the server when you join.

## Map vote

When you join, a window asks you to pick a **MapVote hotkey**. The vote window opens at the end of each match, or any time with that hotkey (a mid-game vote switches once 50 % have voted). It lists DM, TDM, CTF, DOM and LMS maps, so a vote can change the game type too. Kick votes need 51 %.

> [!NOTE]
> The server runs patch 469e; the 469f client from this installer plays on it without problems. Any client from patch 432 on can join.

## Admins

With the admin password (ask the host):

- **Web admin:** [http://{{server_ip}}:5080/ServerAdmin](http://{{server_ip}}:5080/ServerAdmin), user `admin`. Change map, game type, mutators and bots, kick and ban.
- **In game:** console `adminlogin <password>`, then e.g. `admin servertravel CTF-Face?Game=Botpack.CTFGame` or `admin kick <name>`. The MapVote window then has an extra **Admin** tab.

Changes made there last until the server restarts.
