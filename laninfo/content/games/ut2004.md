## Install

Unpack `UT2004.zip` and keep the structure as it is. The `install_files` folder must be writable, the Windows installer writes its `install.log` there.

During installation the game files are unpacked into a temporary `.staging` folder inside the install folder, so plan for about **10 GB** of free space.

### Windows

1. Double-click `install-windows.bat`.
2. Enter the install folder, or press <kbd>Enter</kbd> for the default `C:\Games\UnrealTournament2004`.
3. Confirm the administrator prompt for the Visual C++ runtime at the end.

The folder can also be passed directly:

```bat
install-windows.bat "D:\Games\UT2004"
```

The installer unpacks the game and the 3374 patch, creates the Start Menu folder *Unreal Tournament 2004 ECE* (with *UT2004* and *UnrealEd*) and installs the Visual C++ runtime.

**Uninstall:** there is no uninstaller. Delete the install folder and the Start Menu folder `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Unreal Tournament 2004 ECE`.

If something fails, look at `install_files\install.log`.

### Linux

1. Install the required tools once (needs internet or a package mirror):

   ```sh
   sudo dnf install jq 7zip-standalone-all tar curl   # Fedora
   sudo apt install jq p7zip-full tar curl            # Debian / Ubuntu
   sudo pacman -S jq 7zip tar curl                    # Arch
   ```

   `unshield` is needed too. On normal 64-bit PCs the copy in `install_files` is used automatically; on ARM install the `unshield` package.

2. Open a terminal in the unpacked folder and run:

   ```sh
   bash install-linux.sh
   ```

3. Accept the EULA and answer whether to create the menu entry and desktop shortcut.

The game goes to `~/.local/share/OldUnreal/UT2004`. At the end the installer shows the command to start it. Useful options:

| Option | Meaning |
|---|---|
| `-d <folder>` | Install to another folder |
| `--application-entry install\|skip` | Create the menu entry without asking |
| `--desktop-shortcut install\|skip` | Create the desktop shortcut without asking |
| `-e` | Also install UnrealEd (runs via Wine/umu-launcher) |

## Join the server

- **Server browser:** *Join Game*, then the **LAN** tab.
- **By IP:** open the console (key below <kbd>Esc</kbd>) and type `open {{server_ip}}:7797`.

Maps you don't have (e.g. from the Community Bonus Packs on the server) are downloaded when you join.

## Map vote

The vote opens at the end of each match, and mid-game via <kbd>Esc</kbd> → *Map Voting*. You vote for map and game type together. Kick votes need 51 %.

> [!NOTE]
> The server runs version 3369; the 3374 client from this installer is compatible. Steam and GOG copies (3369) work too.
